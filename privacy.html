Приложение «Выкладка» · действует с 17 октября 2026 года

Что это за приложение

«Выкладка» — личное приложение для Mac. Оно загружает ролики владельца на его собственный канал YouTube. Приложение работает только на компьютере владельца, своего сервера у него нет.

К каким данным Google приложение получает доступ

После того как владелец сам разрешил доступ в окне Google, приложение использует YouTube Data API:

  • youtube.upload — чтобы загружать на канал выбранные владельцем видео с названием и описанием;
  • youtube.readonly — чтобы узнать название и аватар подключённого канала и показать их в приложении.

Где хранятся данные

Ключ доступа от Google, название канала и список публикаций хранятся только в файле на компьютере владельца. Никуда больше они не отправляются: только напрямую в Google при загрузке видео.

Передача третьим лицам

Приложение не продаёт, не передаёт и не показывает данные из аккаунта Google никому. Оно не использует их для рекламы и не обучает на них модели. Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования об ограниченном использовании (Limited Use).

Как отозвать доступ

Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions или кнопкой «Убрать» у канала в самом приложении. Тогда ключ удаляется с компьютера.

Условия YouTube

Загружая видео, владелец пользуется YouTube на Условиях использования YouTube. Обработку данных самим Google описывает Политика конфиденциальности Google.

Privacy Policy

Vykladka app · effective October 17, 2026

What it is. Vykladka is a personal macOS app that uploads the owner's videos to the owner's own YouTube channel. It runs only on the owner's computer and has no server.

Google data accessed. With the owner's consent, the app uses the YouTube Data API scopes youtube.upload (to upload videos with a title and description chosen by the owner) and youtube.readonly (to read the connected channel's name and avatar for display in the app).

Storage. The OAuth token, channel name and the list of posts are stored only in a local file on the owner's computer and are sent nowhere except directly to Google when a video is uploaded.

Sharing. The app does not sell, share or disclose Google user data to anyone, does not use it for advertising and does not use it to train models. Vykladka's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be revoked at any time at myaccount.google.com/permissions or with the “Remove” button in the app, which deletes the token from the computer.

YouTube. By uploading videos the owner uses YouTube under the YouTube Terms of Service; Google's processing is described in the Google Privacy Policy.
