Приложение «Выкладка» · действуют с 17 октября 2026 года

«Выкладка» — личное приложение для Mac. Оно загружает ролики владельца на его собственный канал YouTube и использует для этого сервисы YouTube API (YouTube API Services).

Подключая канал YouTube к «Выкладке», ты соглашаешься с Условиями использования YouTube. Обработку данных компанией Google описывает Политика конфиденциальности Google, а то, как данные обрабатывает само приложение, — Политика конфиденциальности «Выкладки».

Загружай только те ролики, на которые у тебя есть права. Ответственность за содержание роликов несёт владелец канала.

Приложение предоставляется «как есть», бесплатно, без гарантий. Доступ можно отозвать в любой момент на странице настроек безопасности Google.
