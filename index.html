Выкладка

Личное приложение для Mac: публикует свои короткие ролики автора в YouTube Shorts, Instagram Reels и TikTok из одного окна.

«Выкладка» работает только на компьютере автора. Видео загружается на YouTube через официальный YouTube Data API от имени канала, который владелец сам подключил. Приложение не смотрит и не скачивает чужие видео и не собирает данные других людей.

Vykladka is a personal macOS app that uploads the owner's own short videos to their YouTube channel via the official YouTube Data API. It runs only on the owner's computer.

Приложение использует сервисы YouTube API (YouTube API Services). Подключая канал, ты соглашаешься с Условиями использования YouTube; данные Google обрабатывает по Политике конфиденциальности Google.

This app uses YouTube API Services. By connecting a channel you agree to the YouTube Terms of Service; see also the Google Privacy Policy.
